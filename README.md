# Habit Tracker Pro

- A high-performance, streak-based habit tracking application built with React, designed for rigorous historical logging and consistency management.

## 🚀 How to Run Locally
1. **Clone the repository:**
   `git clone <your-repo-url>`
2. **Install dependencies:**
   `npm install`
3. **Start the development server:**
   `npm run dev`
4. **Access the app:** Open your browser to    `http://localhost:5173`

## 🛠️ Tech Stack
* **Frontend:** React (Vite)
* **State Management:** `useReducer` for complex state transitions
* **Data Utility:** `date-fns` for robust calendar arithmetic
* **Styling:** CSS Modules / Custom CSS for responsive grid layouts
* **Storage:** `localStorage` for browser-based persistence

## ✨ Key Features
* **Strict Streak Logic:** Automatically calculates unbroken progress streaks with gap detection.
* **Historical Auditing:** Navigate through past weeks to retroactively log forgotten check-ins.
* **Future-Locking:** Prevents data integrity errors by disabling future-dated entries.
* **Responsive Grid:** A synchronized, column-aligned interface that adjusts based on screen width.
